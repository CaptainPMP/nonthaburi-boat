# เวลาออกเรือ ท่านนทบุรี (Nonthaburi Pier Departure Board)

หน้าเว็บไฟล์เดียว (`nonthaburi-boat.html`) แสดงเวลานับถอยหลังแบบเรียลไทม์ (ทุกวินาที) ของเรือที่ออกจากท่าเรือนนทบุรี แยกเรือ 2 แบบให้เห็นชัดว่าลำไหนใกล้ออกก่อน

- **เรือไฟฟ้า Thai Smile Boat** (Urban Line, นนทบุรี → สาทร)
- **เรือด่วนเจ้าพระยา** (ธงส้ม / ธงเหลืองกลางวัน / ธงเหลือง / ธงแดง Riva Express)

ออกแบบแบบ mobile-first ไม่มี dependency ไม่เรียกอะไรจากอินเทอร์เน็ต เปิดไฟล์ในเบราว์เซอร์ได้เลย (รวมถึง Android แบบออฟไลน์)

## สีแจ้งเตือน

| สี | เงื่อนไข |
|----|----------|
| เหลือง | เหลือเวลา ≤ 30 นาทีก่อนออกเรือ |
| แดง (กะพริบเบา ๆ) | เหลือเวลา ≤ 10 นาทีก่อนออกเรือ |
| เทา | มากกว่า 30 นาที |

การ์ดด้านบนแสดงเรือลำถัดไปของแต่ละประเภท พร้อมป้าย "ใกล้ที่สุด" บนลำที่จะออกก่อน เรือที่ออกไปแล้วจะพับเก็บไว้ในรายการ "ออกไปแล้ว"

## วิธีใช้งาน

**ในเครื่อง / Android**
1. ดาวน์โหลด `nonthaburi-boat.html`
2. เปิดด้วยเบราว์เซอร์ (Chrome ฯลฯ) ใช้งานได้ทันที ไม่ต้องต่อเน็ต

**Deploy บนเว็บ (ไม่บังคับ)**
เปลี่ยนชื่อไฟล์เป็น `index.html` แล้วอัปโหลดขึ้นโฮสต์ static เช่น GitHub Pages, Netlify Drop หรือ Cloudflare Pages

**ทดสอบด้วยเวลาจำลอง** ต่อท้าย URL ด้วย `?t=` (เวลาไทย) เช่น

```
nonthaburi-boat.html?t=2026-10-28T07:34:00
```

## ตรรกะการเลือกตาราง

เวลาอ้างอิงเป็นเวลาไทย (UTC+7) จากนาฬิกาเครื่อง

**Thai Smile**
- มีข้อมูลเฉพาะ 6–31 ต.ค. 2569 นอกช่วงนี้แสดงว่าไม่มีตาราง
- ใช้ชุด "เสาร์–อาทิตย์/วันหยุด" ในวันเสาร์ อาทิตย์ และวันหยุดที่ระบุไว้ (13 และ 23 ต.ค. 2569) ที่เหลือใช้ชุด "จันทร์–ศุกร์"
- ตารางต้นฉบับระบุเวลาออกจากพระนั่งเกล้า ไม่มีเวลาท่านนทบุรีโดยตรง จึงใช้เวลาเดียวกันเป็นค่าเริ่มต้น ปรับส่วนต่างได้ในช่อง "นาที" บนหน้าเว็บ (ค่าถูกจำไว้ใน localStorage ของเบราว์เซอร์)

**เรือด่วนเจ้าพระยา**
- ใช้ตารางปกติตามวันในสัปดาห์
  - จันทร์–ศุกร์: ธงส้ม, ธงเหลืองกลางวัน (ไปวัดราชสิงขร), ธงเหลือง และธงแดง Riva Express (ไปสาทร)
  - เสาร์ / อาทิตย์: เฉพาะธงเหลืองกลางวัน ไปวัดราชสิงขร
- วันที่ **28 ต.ค. 2569** ใช้ตารางพิเศษ เพราะมีซ้อมขบวนพยุหยาตราทางชลมารค ตั้งแต่ 10.30 น. เป็นต้นไป
- วันหยุดนักขัตฤกษ์ยังไม่ได้แยกตารางเรือด่วน (ใช้ตามวันในสัปดาห์) ควรตรวจประกาศอีกครั้ง
- ธงเขียวเหลือง (ปากเกร็ด → สาทร) ไม่ได้ออกจากนนทบุรี จึงไม่แสดง

## แก้ไขข้อมูลตาราง

ข้อมูลทั้งหมดอยู่ในส่วน `<script>` ของไฟล์ HTML:

| ตัวแปร | ความหมาย |
|--------|-----------|
| `TS` | ตาราง Thai Smile: ช่วงวันที่ (`from`/`to`), วันหยุด (`holidays`), เวลาวันธรรมดา (`wd`) และวันหยุด (`hol`) |
| `EX_REG` | ตารางเรือด่วนปกติ แยก `wd` / `sat` / `sun` |
| `EXPRESS` | ตารางพิเศษรายวัน key เป็น `"YYYY-MM-DD"` (ถ้ามี จะใช้แทนตารางปกติในวันนั้น) |

รูปแบบรายการเรือ: `{line:"orange", dest:"วัดราชสิงขร", t:["06:00","06:20"]}`
ค่า `line` ที่ใช้ได้: `orange`, `yellow`, `ymid` (ธงเหลืองกลางวัน), `red`

เพิ่มตาราง Thai Smile รอบถัดไปโดยแก้ `TS.from`, `TS.to`, `TS.holidays` และรายการเวลา

## ข้อจำกัด

- ตารางมาจากภาพประกาศที่ผู้ใช้ส่งมา ควรตรวจกับประกาศอย่างเป็นทางการของผู้ให้บริการก่อนเดินทางจริง เวลาเรืออาจเปลี่ยนตามสภาพการเดินเรือ
- ใช้นาฬิกาของเครื่อง ถ้าเวลาเครื่องผิด ผลก็ผิดตาม
